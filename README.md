# 🤖 ASHISH AI — Personal Voice Assistant

> A futuristic Windows-based personal AI voice assistant with voice control, local AI, YouTube automation, Windows commands, web search, communication tools, and a modern glassmorphism dashboard.

---

## 📌 Overview

**ASHISH AI** is a personal desktop voice assistant built with Python for Windows.

The project combines:

- 🎙️ Voice recognition
- ⌨️ Text commands
- 🧠 Local AI using Ollama
- 🤖 Llama 3.2
- 🌐 Web and Google search
- ▶️ YouTube search and direct playback
- 🪟 Windows system commands
- 📁 File operations
- 💬 WhatsApp messaging
- 📧 Email support
- 🌐 Website shortcuts
- ⏱️ Productivity tools
- 🖥️ Futuristic desktop dashboard
- 🔊 Text-to-speech responses

The main goal of this project is to create a **JARVIS-inspired personal assistant** that can understand natural commands and perform useful tasks on a Windows computer.
